# Databricks Lakehouse Architecture

```text
Raw FHIR Files
        ↓
Databricks Volume Storage
        ↓
Bronze Delta Tables
        ↓
Silver Delta Tables
        ↓
Gold Analytics Tables
        ↓
SQL Analytics
        ↓
Power BI / ML
```

Technologies:

- Databricks
- Delta Lake
- Unity Catalog
- Spark SQL
- PySpark
