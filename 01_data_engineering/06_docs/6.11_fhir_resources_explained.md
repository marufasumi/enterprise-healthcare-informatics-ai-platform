# FHIR Resources Explained

# Overview

FHIR (Fast Healthcare Interoperability Resources) is a healthcare data standard used for exchanging electronic healthcare information.

---

# FHIR Resources Used

| Resource | Purpose |
|---|---|
| Patient | patient demographics |
| Encounter | healthcare visits |
| Condition | diagnoses |
| Observation | vitals and labs |
| Procedure | treatments and procedures |
| MedicationRequest | prescribed medications |
| Immunization | vaccination records |
| CarePlan | care management |
| AllergyIntolerance | allergies |
| Claim | healthcare billing |

---

# Why FHIR Is Important

FHIR enables:
- healthcare interoperability
- standardized healthcare exchange
- scalable healthcare analytics
- enterprise EHR integration
