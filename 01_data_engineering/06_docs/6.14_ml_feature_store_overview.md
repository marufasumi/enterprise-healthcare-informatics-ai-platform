# ML Feature Store Overview

# Purpose

The Gold analytics layer also serves as an ML-ready healthcare feature store.

The feature store provides:
- patient-level ML features
- healthcare risk indicators
- utilization features
- chronic disease features
- financial analytics features
- treatment complexity features

These features support:
- predictive modeling
- healthcare AI
- population health analytics
- risk stratification
- future MLOps pipelines

```text
FHIR JSON
        ↓

        ↓

(clean normalized healthcare data)
        ↓

        ↓
population_health_dashboard
        ↓

```
