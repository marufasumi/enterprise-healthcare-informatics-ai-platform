# Enterprise Healthcare Informatics AI Platform

# Project Summary

This project implements an enterprise healthcare analytics and clinical AI platform using Databricks Lakehouse Architecture.

The platform processes FHIR R4 healthcare data into scalable analytics-ready Delta Lake tables supporting:

- healthcare analytics
- population health analytics
- healthcare financial analytics
- SQL analytics
- Power BI dashboards
- ML-ready healthcare feature engineering

---

# Technology Stack

| Category | Technologies |
|---|---|
| Data Engineering | Databricks, PySpark, Delta Lake |
| Analytics | Spark SQL, Power BI |
| Healthcare Standards | FHIR R4 |
| Storage | Unity Catalog, DBFS Volumes |
| Machine Learning | ML-ready Gold feature layer |
| Architecture | Medallion Lakehouse Architecture |

---

# Architecture

```text
FHIR JSON Files
        ↓
Bronze Layer
(raw healthcare ingestion)
        ↓
Silver Layer
(clean normalized healthcare data)
        ↓
Gold Layer
(business analytics + ML feature engineering)
        ↓
SQL Analytics Layer
        ↓
Power BI Dashboards
        ↓
Machine Learning Pipelines
```

# Medallion Architecture

# Bronze Layer

## Purpose

Stores raw healthcare FHIR resources without transformation.

## Bronze Tables

- patient_raw
- encounter_raw
- condition_raw
- observation_raw
- procedure_raw
- medication_request_raw
- immunization_raw
- careplan_raw
- allergy_intolerance_raw
- claim_raw

# Silver Layer

## Purpose
