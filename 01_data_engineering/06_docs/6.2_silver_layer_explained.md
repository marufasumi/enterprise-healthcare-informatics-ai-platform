# Silver Layer Documentation

## Purpose

The Silver layer normalizes and cleans healthcare FHIR resources into analytics-ready tables.

---

# Silver Layer Responsibilities

- JSON parsing
- field extraction
- datatype standardization
- patient linkage
- encounter linkage
- healthcare terminology extraction
- null handling
- date normalization

---

# Silver Tables

| Table | Purpose |
|---|---|
| patient_clean | normalized demographics |
| encounter_clean | normalized encounters |
| condition_clean | diagnosis normalization |
| observation_clean | vitals and labs |
| procedure_clean | procedures |
| medication_request_clean | medications |
| immunization_clean | vaccinations |
| careplan_clean | care management |
| allergy_intolerance_clean | allergies |
| claim_clean | healthcare claims |

---

# Example Transformations

## Patient Layer

Extracted:
- patient_id
- gender
- birth_date
- marital_status
- city
- state

## Encounter Layer

Extracted:
- encounter_class
- encounter_status

## Observation Layer

Extracted:
- BMI
- glucose
- HbA1c
- oxygen saturation
- heart rate

## Claim Layer

Extracted:

- payment amount
- total cost
