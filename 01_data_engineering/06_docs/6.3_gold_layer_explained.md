# Gold Layer Documentation

## Purpose

The Gold layer creates business-ready healthcare analytics and ML feature tables.

---

# Gold Layer Goals

- executive dashboards
- population health analytics
- healthcare KPIs
- SQL analytics
- ML feature engineering
- Power BI integration

---

# Gold Tables

| Table | Purpose |
|---|---|
| patient_summary | patient analytics |
| encounter_utilization_summary | utilization analytics |
| chronic_disease_summary | chronic disease analytics |
| medication_summary | medication burden analytics |
| observation_vitals_labs_summary | vitals and labs analytics |
| procedure_careplan_summary | treatment complexity analytics |
| claim_cost_summary | healthcare financial analytics |
| population_health_dashboard | executive dashboard table |
