# Databricks Setup Guide

# Environment

Platform:
- Databricks Community Edition

---

# Technologies

- Databricks Notebooks
- PySpark
- Spark SQL
- Delta Lake
- Unity Catalog

---

# Setup Steps

1. Create Databricks account
2. Create healthcare catalog
3. Create Bronze/Silver/Gold schemas
4. Create DBFS volumes
5. Upload FHIR JSON files
6. Run Bronze ingestion notebooks
7. Run Silver cleaning notebooks
8. Run Gold analytics notebooks

---

# Medallion Architecture

FHIR JSON
→ Bronze
→ Silver
→ Gold

---

# Final Output

Enterprise healthcare analytics platform with:
- SQL analytics
- Power BI support
- ML-ready feature store
