# Enterprise Healthcare Data Dictionary

# Overview

This document describes the major healthcare entities used throughout the platform.

---

# Patient Domain

| Table | Description |
|---|---|
| patient_clean | normalized patient demographics |

Key Fields:
- patient_id
- gender
- birth_date
- marital_status
- city
- state

---

# Encounter Domain

| Table | Description |
|---|---|
| encounter_clean | healthcare utilization encounters |

Key Fields:
- encounter_id
- patient_id
- encounter_class
- encounter_duration_hours

---

# Condition Domain

| Table | Description |
|---|---|
| condition_clean | diagnosis and chronic disease data |

Key Fields:
- diagnosis_code
- diagnosis_display

---

# Observation Domain
