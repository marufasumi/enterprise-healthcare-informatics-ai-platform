# Enterprise Healthcare Informatics AI Platform

---

# Overview

This guide explains how to execute the complete enterprise healthcare lakehouse pipeline in Databricks.

The platform processes FHIR R4 healthcare data using a Medallion Architecture:

```text
FHIR JSON Files
        ↓
Bronze Layer
(raw ingestion)
        ↓
Silver Layer
(clean normalized healthcare data)
        ↓
Gold Layer
(business analytics + ML feature engineering)

Technology Stack
Databricks
PySpark
Delta Lake
Spark SQL
Unity Catalog
FHIR R4

Project Architecture
Bronze Layer

Purpose:

raw healthcare ingestion
preserve original FHIR structure
support replayability
Silver Layer

Purpose:

healthcare normalization
patient linkage
encounter linkage
analytics preparation
Gold Layer

Purpose:

healthcare analytics
population health KPIs
financial analytics
SQL analytics
ML feature engineering
Prerequisites

Before running the pipeline:

Create Databricks account
Create healthcare catalog
Create Bronze/Silver/Gold schemas
Create DBFS volume
Upload FHIR JSON files
Step 1 — Create Databricks Environment
Create Databricks Account

Use:

Databricks Community Edition
Step 2 — Create Healthcare Catalog

Run:

CREATE CATALOG healthcare_catalog;
Step 3 — Create Schemas

Run:

CREATE SCHEMA healthcare_catalog.bronze;
CREATE SCHEMA healthcare_catalog.silver;
CREATE SCHEMA healthcare_catalog.gold;
Step 4 — Create Volume

Run:

CREATE VOLUME healthcare_catalog.bronze.raw_fhir_files;
Step 5 — Upload FHIR Files

Upload raw FHIR JSON/NDJSON files into:

/Volumes/healthcare_catalog/bronze/raw_fhir_files/
