# claim_clean Schema

| Column | Description |
|---|---|
| claim_id | unique claim identifier |
| patient_id | linked patient |
| encounter_id | linked encounter |
| claim_type_code | institutional or pharmacy |
| total_claim_amount | total claim cost |
| payment_amount | payment amount |
| billing_start | billing start date |
| billing_end | billing end date |

---

# Purpose

Normalized healthcare financial claims table for healthcare cost analytics.
