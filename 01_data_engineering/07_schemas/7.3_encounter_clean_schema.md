# encounter_clean Schema

| Column | Description |
|---|---|
| encounter_id | unique encounter identifier |
| patient_id | linked patient identifier |
| encounter_class | encounter type (AMB, EMER, IMP) |
| encounter_status | encounter status |
| encounter_type_text | encounter description |
| encounter_start | encounter start datetime |
| encounter_end | encounter end datetime |
| encounter_duration_hours | encounter duration in hours |
| provider_reference | linked provider reference |

---

# Purpose

Normalized healthcare encounter table for utilization analytics and operational reporting.
