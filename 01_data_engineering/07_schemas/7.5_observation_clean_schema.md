# observation_clean Schema

| Column | Description |
|---|---|
| observation_id | unique observation identifier |
| patient_id | linked patient identifier |
| encounter_id | linked encounter identifier |
| observation_code | observation code |
| observation_description | observation description |
| observation_value | numeric observation value |
| observation_unit | measurement unit |
| observation_datetime | observation timestamp |

---

# Purpose

Normalized vitals and laboratory observation table for clinical analytics and ML feature engineering.
