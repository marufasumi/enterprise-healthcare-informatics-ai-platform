# procedure_clean Schema

| Column | Description |
|---|---|
| procedure_id | unique procedure identifier |
| patient_id | linked patient identifier |
| encounter_id | linked encounter identifier |
| procedure_code | procedure code |
| procedure_description | procedure description |
| procedure_status | procedure status |
| procedure_start | procedure start datetime |
| procedure_end | procedure end datetime |
| procedure_duration_hours | procedure duration |

---

# Purpose

Normalized healthcare procedure table for treatment burden and utilization analytics.
