# medication_request_clean Schema

| Column | Description |
|---|---|
| medication_request_id | unique medication request identifier |
| patient_id | linked patient identifier |
| encounter_id | linked encounter identifier |
| medication_code | medication code |
| medication_name | medication description |
| medication_status | medication status |
| intent | medication intent |
| authored_datetime | prescription datetime |

---

# Purpose

Normalized medication prescribing table for pharmacy analytics and polypharmacy analysis.
